Class vs ID მაგალითი

ეს ტექსტი არის პირველი აბზაცი — მას აქვს class="highlight" და id="first". ერთხელვე გამოიყენება id და სხვადასხვათომიგები class.

ეს მეორე აბზაცი აქვს class="highlight muted" და id="second". class 'highlight' განსაზღვრავს საერთო სტილს, 'muted' ფერ-შეხედულებას და იდ 'second' კიდე ბორდერს აქცევს დეშედს.
